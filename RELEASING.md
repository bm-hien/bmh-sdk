# Releasing `@bmhien/bot`

Releases are published from GitHub Actions with npm trusted publishing.

## One-time npm setup

1. Sign in with the `bmhien` npm account, which owns the personal `@bmhien`
   scope.
2. From a clean `main` checkout, run all checks and make the first publication:

   ```bash
   npm ci
   npm run check
   npm publish --access public --provenance=false
   ```

   The explicit override is only for this local bootstrap publication. Package
   provenance is generated by GitHub Actions for later releases.
3. Open the new `@bmhien/bot` package settings on npm and add a trusted publisher:
   organization/user `bm-hien`, repository `bmh-sdk`, workflow
   `.github/workflows/publish.yml`, environment left empty.
4. Require two-factor authentication for maintainers and automation changes.
5. Verify the bootstrap package from a clean directory, then create the matching
   GitHub release. The workflow recognizes the existing version, verifies it,
   and does not attempt a duplicate publication:

   ```bash
   npm view @bmhien/bot@0.1.0 version dist.integrity
   npm install @bmhien/bot@0.1.0
   ```

Do not create release `v0.1.0` before the bootstrap publication because the
trusted publisher cannot be configured until the npm package exists. Later
releases use GitHub's short-lived OIDC identity and do not store a long-lived npm
token in repository secrets.

## Publish a version

1. Update `version` in `package.json` and `package-lock.json`.
2. Update the Bot API version and tests if Telegram's API surface changed.
3. Run `npm run check` and `npm audit`.
4. Merge the release commit into `main`.
5. For versions after the bootstrap release, create a GitHub release whose tag
   exactly matches `v<package version>`, for example `v0.2.0`.

The release workflow verifies the tag, repeats all package checks, and runs
`npm publish --access public` with provenance.

After publication, verify both registry metadata and a clean installation:

```bash
npm view @bmhien/bot version dist.integrity
npm install @bmhien/bot
```
